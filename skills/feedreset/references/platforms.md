# Native controls on iPhone and connected accounts

Use the labels actually present on the person's app, account, language and region. A recommendation feed, a following feed and a watch log answer different questions. Inspect the permissions of the available connector for each operation. This package contains no platform credentials or private API clients. A chat with screenshots can diagnose all four networks; writes need an authorized control or the owner's tap.

| Network | Diagnose | Reduce or rebuild | Encourage and verify |
| --- | --- | --- | --- |
| Instagram | Take consecutive Home recommendations, Explore tiles or Reels separately. A friend's original Story is a different surface from a reposted Reel. | Use the item's menu → **Not interested** when present. For an explicit fresh start, profile menu → **Content preferences** → **Reset suggested content** if available. The reset covers Feed, Explore and Reels. Inspect the confirmation screen before committing. | Use **Favorites** for an eligible chosen account or **Following** to read selected sources. Verify favorite membership or the on-screen feedback. After a reset, sample again later as recommendations repersonalize. [Meta's reset and preference controls](https://about.fb.com/news/2024/11/introducing-recommendations-reset-instagram/) |
| YouTube | Sample Home and Shorts separately. Recent watch history can explain an unwanted signal. Treat a history export as evidence of consumption only. | Use the recommended video's menu → **Not interested**. Use **Don't recommend channel** only with evidence for the whole channel and specific authority. For an accidental view, open **History**, locate the exact video, then remove that entry if authorized. Time-range deletion may also remove search history. | Curate a real channel through **Subscribe** when authorized. For individual videos, create a reading/watch queue. Verify the subscription state or disappearance of the exact history entry. A channel may still be discoverable elsewhere. [Recommendation controls](https://support.google.com/youtube/answer/6342839?hl=en) · [History controls](https://support.google.com/youtube/answer/95725?hl=en) |
| TikTok | Sample **For You** separately from Following. Distinguish a recurring format, creator and topic. | Long-press a post or use Share → **Not interested**. Where offered, **Content preferences** provides keyword filters, **Manage topics** and **Refresh your For You feed**. The refresh changes For You recommendations and cannot be undone. Verify the scope on the final screen. | Prefer topic adjustments and actual chosen sources; open **Following** for a deliberate session. Verify saved topic settings, follow state or the reset confirmation. [Refresh](https://support.tiktok.com/en/account-and-privacy/account-privacy-settings/refresh-your-for-you-feed) · [Manage topics](https://support.tiktok.com/en/account-and-privacy/account-privacy-settings/manage-topics) · [How recommendations work](https://support.tiktok.com/en/using-tiktok/exploring-videos/how-tiktok-recommends-content) |
| X | Sample **For you**, **Following** and a chosen List separately. A chronological timeline returned by a connector cannot stand in for For you. | Use the item's negative feedback when present. For a recurring, unambiguous term, offer **Muted words** with Home scope. Review language, ambiguity and duration before adding a term. There is no whole-feed reset implemented here. | A private, pinned List can open a parallel feed while preserving the person's existing follows. Verify membership, pin and visibility. Automated account changes require a permitted integration. X prohibits non-API website scripting; offer native taps where the integration lacks an operation. [Timeline](https://help.x.com/en/using-x/x-timeline) · [Muting](https://help.x.com/en/using-x/advanced-x-mute-options) · [Lists](https://help.x.com/en/using-x/x-lists) · [Automation rules](https://help.x.com/en/rules-and-policies/x-automation) |

If the device is inaccessible, request a few consecutive screenshots of one feed. Return the diagnosis and targeted tap list in the same conversation. On iOS a time-of-day Shortcut can launch actions exposed by the chosen host. Check those actions and verify execution on the actual device before calling the job automatic. [Apple Shortcuts automations](https://support.apple.com/guide/shortcuts/add-automations-apdfbdbd7123/ios)
